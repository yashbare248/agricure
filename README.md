# AgriCure

AgriCure is an AI-powered crop health assistant and diagnosis platform. It helps farmers scan crops, detect diseases, get treatment plans, track local weather for spray timings, and chat with an AI agronomist in English, Hindi, and Marathi.

## Features

- **AI Disease Diagnosis**: Scan crop leaves and get instant health analysis and treatment recommendations.
- **AI Agronomist Chat**: Ask questions and get advice regarding crop health, soil, and fertilizing.
- **Local Weather & Spray Advisory**: View current weather and get automated suggestions for the best times to spray pesticides or irrigate.
- **Soil Profiling**: Monitor and understand your soil health metrics.
- **Disease mapping**: See geo-location and satellite views of crop disease trends.

## Development

To run the application locally, you will need Node.js and npm installed.

```sh
# Clone the repository
git clone https://github.com/yashbare248/agricure.git
cd agricure

# Install dependencies
npm install

# Run the development server
npm run dev
```

## Tech Stack

- **Framework**: TanStack Start / Router
- **Runtime**: Node / Bun
- **Language**: TypeScript
- **UI & Styling**: React, Tailwind CSS, shadcn/ui
- **Database / Backend**: Supabase
